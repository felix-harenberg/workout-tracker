# v0.6.0-design.3 – Supersets, running volume, notes (preview)
The blog-look test version with new features. Built from the branch `design/blog`; it is not merged into the main version yet.

## New
- **Running volume:** a third page "Laufen" on the start screen. Log only the kilometres of a run (today, yesterday, the day before or any date from the calendar). A ring fills up with this week's km against your weekly goal; the goal dialog suggests last week's goal + 10 %. Past weeks show as bars with the goal behind them
- **Supersets:** long-press an exercise in a workout, tap the others in the order you do them, then ⇄ Verbinden. A superset shows as one block (A1, A2, …) and can have a name and notes. On the sets screen, tabs switch between its exercises, and after saving a set the next exercise opens with "Satz hinzufügen" ready. A new workout with the same name takes the supersets along
- **Add a set from a plus row:** the fixed input panel is gone. "+ Satz" under the sets opens the same dialog as editing a set, prefilled like before
- **Notes per exercise:** e.g. "Sitz auf Stufe 4". They belong to the exercise and show up again every time
- **Start screen:** the blue line under the tabs slides to the active page
- **Backup:** the CSV export has the exercise notes and the superset letter; runs come as a third file

## Update
Install over v0.5.2 or an earlier design version – no need to uninstall, all data is kept. The database is upgraded on the first start (migrations 5 to 8).

Going back to v0.5.2 afterwards only works by uninstalling first, which deletes your data. Export a CSV backup before you do that.
