# v0.6.0-design.2 – Blog look (preview)
A test version with a new look, taken from my blog: black, white and one blue. Built from the branch `design/blog`; it is not merged into the main version yet.

## New
- **New design:** no glass, no glow, no round corners. Thin lines separate the rows, like the post list on the blog
- **Fonts:** screen titles in Instrument Serif italic, workout and exercise names in Archivo Expanded, dates, sets and labels in JetBrains Mono
- **Blue ring:** workouts this month on the start screen, sets of the newest week in the stats
- **New app icon and splash screen:** the biceps as a blue outline inside a blue square
- **Own dialogs:** deleting a workout or exercise, editing a set, bodyweight and goal now match the app instead of Android's default. Deleting is the only red in the app
- **Edit a set** with the same ±2.5 kg and ±1 rep buttons as the input
- **Stats:** tap a bar and its numbers stay in a box above the chart, tap it again to close it

## Update
Install over v0.5.2 or v0.6.0-design.1 – no need to uninstall, all data is kept.

Going back to v0.5.2 afterwards only works by uninstalling first, which deletes your data. Export a CSV backup before you do that.

## Fixed since design.1
- Tapping a bar in the stats did nothing; now it shows the week's details again
